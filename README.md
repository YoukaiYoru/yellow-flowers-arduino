# 🌼 Feliz primavera con Arduino UNO Q

Proyecto para la matriz LED azul integrada de 8×13 del Arduino UNO Q. Muestra el texto “FELIZ PRIMAVERA” y después una flor, sin componentes externos.

## Materiales

- Arduino UNO Q
- Cable USB-C para programarlo

## Conexiones

No hay conexiones externas: el UNO Q incluye una matriz LED azul de 8×13 controlada por su microcontrolador.

## Funcionamiento

El texto `FELIZ PRIMAVERA` se desplaza por la matriz y luego aparece una flor.

Abre `sketch/sketch.ino` en Arduino IDE o Arduino App Lab, selecciona **Arduino UNO Q** y carga el programa en el MCU.
